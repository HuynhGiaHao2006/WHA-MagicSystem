# WHA-MagicSystem
A Python-based gesture recognition engine that captures hand-drawn canvas strokes, processes input point clouds, and extracts spatial/structural spell attributes in real time, replicating the magic system from the anime Witch Hat Atelier in Python.

Status: 
- Finished the parser pipeline, processing user's handdrawn input and returning attributes of the drawing that will affect the spell.
- Spell effect renderer and UI is in process.
